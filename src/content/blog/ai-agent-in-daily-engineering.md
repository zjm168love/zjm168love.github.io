过去半年，我逐渐把 AI Agent 从"聊天助手"变成"工程同事"。区别在于：助手回答你的问题，同事替你完成一段有明确边界、可验证的工作。

我的用法大致分三层：

1. **重复性工程**：补测试、写样板代码、生成文档初稿、做小范围重构提案。这类工作目标清晰、结果可跑可测，最适合交给 Agent。
2. **理解与梳理**：让 Agent 读一段陌生代码后输出结构梳理和数据流说明，作为我自己阅读前的"地图"，能显著降低上手成本。
3. **决策仍留给人**：架构取舍、边界划分、性能与一致性的权衡，这些我坚持自己做。Agent 给选项，我做判断。

一个关键体会：**给 Agent 的上下文质量，决定产出质量**。把需求写清楚、把约束列明白、把"完成"的定义给出来，比反复追问有效得多。
